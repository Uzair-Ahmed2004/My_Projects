PROJECT OVERVIEW:
This project presents an autonomous maze solver robot developed using Arduino Uno, an 8-channel IR sensor array, and an L298N motor driver. The robot continuously senses the black guiding path, processes sensor data in real time, and controls two DC geared motors using a PID-based line following algorithm.
The system is designed following the principles of Embedded Systems, Closed-Loop Control, and Real-Time Decision Making.


Features
8 IR Line Sensor Array
PID Line Following
PWM Speed Control
Differential Drive Robot
Closed Loop Feedback Control
Real-Time Navigation
Modular Code Structure
